## 6주차 JavaScript 이벤트와 동적 UI 실습

### 구현한 기능

click 이벤트는 버튼을 클릭하면 밝은 테마와 어두운 테마가 바뀌고, 버튼에 표시되는 문구도 함께 변경됩니다.

input 이벤트는 내 차종을 입력하면 글자 수가 실시간으로 표시되도록 했습니다.
입력할 수 있는 글자 수는 최대 10자로 제한했습니다.

change 이벤트는 체크박스에 체크하면 안내 문구와 배경색이 바뀌면서 버튼이 활성화됩니다.
체크를 해제하면 다시 원래 상태로 돌아갑니다.

탭 UI는 주요 기능 3개를 탭으로 만들었습니다.
탭을 선택하면 해당 설명만 보이도록 했습니다.

모바일처럼 화면이 좁아지면 탭 버튼 3개가 세로로 배치되도록 했습니다.

### 테스트 결과

화면 너비를 1100px, 768px, 390px로 바꿔 가며 확인했습니다.
1100px에서는 탭 버튼이 가로로 배치되었고, 768px과 390px에서는 세로로 표시됩니다..

탭 3개를 각각 눌러 보니 선택한 탭의 내용만 정상적으로 표시됩니다.
밝은 테마와 어두운 테마에서도 탭 전환이 잘 되는 것을 확인했습니다.

차종을 입력할 때마다 글자 수가 바뀌는 것도 확인했고, 체크박스를 선택하거나 해제했을 때 안내 문구와 색상, 버튼 상태가 제대로 변경되는지도 테스트했습니다.

기존에 만들었던 5주차 이메일 신청 기능도 다시 확인했으며 정상적으로 작동합니다.

### 추가로 수정한 부분

어두운 테마에서 안내 문구가 잘 보이지 않는 부분이 있어 글자색을 수정했습니다.

이전에 배운 CSS를 활용해 탭 버튼의 여백을 조정하고 모서리를 둥글게 만들었습니다.
