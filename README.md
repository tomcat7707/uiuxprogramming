# 차와 함께 오래 - 10주차 메뉴와 목록 기능

## 10주차 학습 내용

기존 차량 점검 상담 메모에 메뉴 이동과 목록 필터 기능을 추가함.

- 이용 방법, 상담 메모 작성, 임시 보관함 메뉴를 구성함.
- 메뉴를 누르면 해당 위치로 이동하고 현재 선택한 메뉴가 표시되도록 함.
- 보관한 메모를 전체, 한 번, 가끔, 자주로 나누어 볼 수 있도록 함.
- 필터를 선택하면 해당하는 메모의 개수와 내용이 표시됨.
- 모바일에서도 메뉴를 열고 닫을 수 있도록 수정함.

## 메뉴와 필터

- 이용 방법: 상담 메모 작성 순서를 안내함.
- 상담 메모 작성: 차량 증상과 경고등 정보를 입력함.
- 임시 보관함: 보관한 메모를 확인하거나 보관을 취소할 수 있도록 함.

목록 필터는 메모 작성 시 선택한 증상 발생 빈도를 기준으로 구분함.

## 테스트 결과

상담 메모 작성 메뉴에서 메모를 작성하고 임시 보관한 뒤, 임시 보관함으로 이동하여 필터를 하나씩 바꿔가며 확인함.

- 메뉴를 누르면 해당 위치로 이동하고 선택한 메뉴가 표시됨.
- 전체, 한 번, 가끔, 자주 필터에 따라 메모가 표시됨.
- 해당하는 메모가 없으면 안내 문구가 표시됨.
- 모바일에서 메뉴를 열고 목적지를 선택하면 메뉴가 자동으로 닫힘.
- 기존 메모 작성과 보관 취소 기능도 정상 작동함.

※ 현재 메모는 한 건만 임시 보관할 수 있으며, 새로고침하면 보관한 내용이 사라짐.
