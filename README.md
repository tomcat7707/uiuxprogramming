# 차와 함께 오래 - 내 차 점검 상담 메모

## 사용자와 목표

- 차량 관리에 익숙하지 않은 운전자는 차에서 평소와 다른 현상을 느껴도 정비소에 어떻게 설명해야 할지 막막할 수 있다.
- 이 기능은 운전자가 직접 겪은 증상과 발생 빈도, 경고등 정보를 정리해 정비소에 문의할 때 참고할 메모를 만들 수 있도록 구성했다.
- 작성한 내용을 마지막으로 확인하고 완료 안내가 나오면 메모 작성이 끝난다.

## 사용자의 흐름

1. 상담 준비하기

   점검 상담 준비 확인란에 체크하고 시작 버튼을 누른다. 안내창을 확인한 뒤 메모 작성을 시작한다.

2. 증상 입력하기

   차량에서 평소와 다르게 느낀 점을 입력한다. 아무것도 입력하지 않으면 안내 문구가 나오며, 같은 화면에서 내용을 입력할 수 있다.

3. 발생 빈도와 경고등 선택하기

   증상이 얼마나 자주 나타나는지 선택한다. 경고등을 본 적이 있다면 해당 항목에 체크하고 경고등 색상도 선택한다.

4. 작성한 내용 확인하기

   입력한 증상과 발생 빈도, 경고등 정보를 확인한다. 잘못 입력한 내용이 있으면 이전 단계로 돌아가 수정할 수 있다.

5. 메모 작성 마치기

   상담 메모 작성 완료 안내와 정리된 내용을 확인한다. 다른 내용을 작성하고 싶다면 다시 시작할 수 있다.

## 인터랙션 시나리오

1. 상담 메모 시작
- 점검 상담 준비 확인란에 체크하면 시작 버튼이 활성화된다. 버튼을 누르면 안내창이 열리고,
            '돌아가기' 또는 Esc 키로 닫으면 체크가 해제된 채 처음 화면으로 돌아온다.
- '메모 작성 시작하기'를 누르면 증상 입력 화면으로 이동한다.

2. 차량 이상 증상 입력
- 운전자가 차량에서 평소와 다르게 느낀 점을 직접 입력한다.
- 내용 없이 다음 단계로 넘어가려고 하면 '차량에서 느낀 현상을 입력해 주세요.'라는 문구가 나타나고 입력창에 커서가 놓인다.
            공백만 입력한 경우도 마찬가지다.
- 정상적으로 입력하면 안내 문구가 사라지고, 작성한 내용을 유지한 채 다음 단계로 넘어간다.

3. 발생 빈도와 경고등 선택
- 증상 발생 빈도는 슬라이더로 선택한다. '한 번', '가끔', '자주' 세 단계이며 기본값은 '가끔'이다.
            슬라이더를 움직이면 선택한 값이 바로 표시된다.

- 경고등을 본 경우 체크박스를 선택하고, 나타나는 항목에서 '빨간색', '노란색', '잘 모르겠음' 중 하나를 고른다.
            체크를 해제하면 색상 선택 항목은 숨겨진다.

- 선택을 마치고 '작성 내용 확인하기' 버튼을 누르면 확인 화면으로 이동한다.

4. 작성 내용 확인 및 수정
- 입력한 증상과 발생 빈도, 경고등 정보를 한 화면에서 확인한다.
- 수정할 내용이 있으면 이전 단계로 돌아갈 수 있으며, 입력했던 값은 그대로 남아 있다.
            증상 설명도 입력 화면으로 돌아가 고칠 수 있다.
- 수정한 내용은 확인 화면에 반영되며, 이상이 없으면 '메모 작성 완료하기'를 누른다.

5. 작성 완료 및 다시 시작
- 메모 작성이 끝나면 완료 안내와 정리된 내용이 나타난다. 정비소에 문의할 때 참고하는 용도이며 별도로 저장하거나 전송하지 않는다.
- '다시 작성하기'를 누르면 증상 입력 내용과 경고등 선택, 오류 문구, 진행 상태가 초기화되고 발생 빈도도 '가끔'으로 돌아간다.
- 기존 웹사이트의 차종 입력, 화면 테마, 기능 탭 등은 초기화하지 않고 그대로 유지한다.

## 테스트 결과

- 정상 진행: 증상 입력부터 발생 빈도와 경고등 선택, 내용 확인, 작성 완료까지 정상 작동함.
- 입력 오류: 내용을 입력하지 않거나 공백만 입력하면 다음 단계로 넘어가지 않고, 입력창에 빨간 테두리와 안내 문구가 표시됨.
- 취소: 안내창에서 '돌아가기'를 누르거나 Esc 키를 누르면 창이 닫히고 준비 체크도 해제됨.
- 이전 및 수정: 이전 화면으로 돌아가도 작성한 내용이 남아 있으며 수정한 내용도 확인 화면에 제대로 반영됨.
- 다시 작성하기: 다시 시작하면 입력한 증상과 경고등 선택이 초기화되고 발생 빈도는 기본값인 '가끔'으로 돌아간다.
- 화면 확인: 데스크톱과 모바일에서 입력창과 버튼을 조작해 봤으며, 기존 기능도 정상적으로 작동하는 것을 확인함.
