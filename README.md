## 5주차 JavaScript 실습

### 사용자 행동

이메일을 입력하고 알림 신청하기 버튼을 누르면 신청할 수 있도록 했습니다.
Enter 키를 눌러도 신청할 수 있습니다.

### 화면 변화

이메일을 입력하지 않고 버튼을 누르면 입력 안내가 나오면서 커서가 이메일 입력칸으로 포커스 이동하도록 했습니다.
이메일을 입력하고 신청하면 신청완료 문구가 나오고 버튼도 신청완료 상태로 바뀝니다.

### 작성한 내용

script.js 파일을 만들고 HTML에 연결했습니다.
if 조건문과 함수를 사용해서 이메일 입력 여부를 확인하도록 했습니다.
이메일 입력 후 폼을 제출하면 안내 문구와 버튼 상태가 바뀌도록 만들었습니다.
