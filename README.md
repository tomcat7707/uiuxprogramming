# 차와 함께 오래 - 9주차 입력 폼과 제출 처리

## 9주차 학습 내용

기존 차량 점검 상담 메모에 HTML 폼과 입력 검사, 제출 상태 안내 기능을 추가함.

- 이상 증상은 2~60자로 제한하고 글자 수와 입력 상태를 실시간으로 표시함.
- 경고등을 체크하면 색상 선택 항목이 나타나고 해제하면 숨겨지고 비활성화됨.
- `FormData`로 입력값을 가져와 완료 화면에 표시함.
- 제출 중에는 버튼을 비활성화하고 완료 또는 실패 여부를 안내함.
- 제출에 실패해도 입력 내용은 그대로 남겨 다시 시도할 수 있도록 함.

## 테스트 결과

- 정상 입력과 제출 후 완료 화면이 표시되는 것을 확인함.
- 입력 조건에 맞지 않으면 다음 단계로 넘어가거나 제출할 수 없도록 함.
- 경고등 체크를 해제하면 색상 정보가 제출되지 않는 것을 확인함.
- ?save-error=1로 제출 실패 상황을 테스트했으며, 기존 임시 보관 기능도 정상 작동함을 확인함.

※ 제출 실패는 실습을 위해 만든 테스트 상황이며, 임시 보관한 내용은 새로고침하면 사라짐.
