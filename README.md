# 차와 함께 오래 - 11주차 웹 접근성 개선

## 11주차 학습 내용

이번 주에는 글자가 잘 보이지 않거나 키보드로 사용하기 불편했던 부분을 찾아 수정함.

마우스를 사용하지 않아도 메뉴 이동과 상담 메모 작성이 편리하도록 개선함.

## 수정한 내용

- 글자 색상: 어두운 테마에서 잘 보이지 않던 제목, 입력 글자, 오류 안내 문구를 밝게 수정함.
- 메뉴와 필터: 선택한 메뉴와 필터를 색상뿐 아니라 굵은 글씨와 밑줄로도 구분하도록 함.
- 이미지 설명: 자동차 점검 사진에 어떤 장면인지 알 수 있도록 대체 텍스트를 수정함.
- 본문 바로가기: Tab 키를 처음 누르면 본문 바로가기 링크가 나타나고 Enter 키로 이동할 수 있도록 함.
- 모바일 메뉴: 메뉴가 열린 상태에서 Esc 키를 누르면 닫히고 메뉴 버튼으로 초점이 돌아오도록 함.
- 상담 메모: 작성 내용 확인 화면과 메모 보관 취소 후에 키보드 초점이 알맞은 위치로 이동하도록 수정함.

## 개선 전 → 개선 후

1. 어두운 테마에서 글자가 잘 보이지 않음 → 글자색을 밝게 바꿔 읽기 쉽게 수정함.
2. 선택한 메뉴를 색상으로만 구분함 → 굵은 글씨와 밑줄을 추가함.
3. 키보드로 상단 메뉴를 모두 지나가야 함 → 본문 바로가기 기능을 추가함.
4. 모바일 메뉴를 키보드로 닫기 어려움 → Esc 키로 닫고 메뉴 버튼으로 돌아오도록 함.
5. 메모 보관 취소 후 초점 위치가 불분명함 → 취소 안내 문구로 초점이 이동하도록 수정함.

## 확인한 내용

- 밝은 테마와 어두운 테마에서 글자와 안내 문구가 잘 보이는지 확인함.
- Tab과 Enter 키로 본문 이동과 상담 메모 작성이 가능한지 확인함.
- 모바일 메뉴가 Esc 키로 닫히고 메뉴 버튼으로 돌아오는지 확인함.
- 상담 메모의 입력 오류와 작성 실패 안내가 제대로 표시되는지 확인함.
- 목록 필터 선택과 메모 보관 취소 기능을 확인함.
